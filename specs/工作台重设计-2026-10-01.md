# 工作台重设计（2026-10-01 第二轮）

> 触发：用户反馈「工作台 UI 全部混乱，文案不清晰，很多功能不知道是做什么的（像是校验），
> 文字全都黏在一起，完全混乱」。这是结构问题，不是某个 CSS 值的问题。
>
> 本文是重设计的作业依据。视觉系统仍以 `specs/claude-DESIGN.md` 为准，
> 交互参考 `../_ui-audit/Claude风格交互参考资料.md`。

## 一、用户指出的具体症状（逐条要解决）

| # | 症状 | 截图证据 |
| --- | --- | --- |
| 1 | **文字黏在一起** | 对话区里工具轮摘要与正文挤成一团，行距/段距不足 |
| 2 | **不知道「校验」是干什么的** | 右侧校验卡只写了「校验只看沙箱里当前的代码」，没说清"这步产出什么、我该看什么" |
| 3 | **信息重复** | 「模型档案已删除」在卡片头尾各出现一次；「沙箱就绪」也是 |
| 4 | **功能边界不清** | 对话卡里塞了模型档案下拉、消息流、输入框、提示词发送按钮——不知道哪个是主体 |
| 5 | **布局错位** | 对话卡内嵌滚动区被日志挤压，出现"文字叠在一起"的观感 |

## 二、重设计目标

### 2.1 一句话说清每张卡在做什么

每张卡的标题下方加**一行说明**（不是术语，是"这一步你要做什么"）：

| 卡 | 说明文案 |
| --- | --- |
| 内置对话 | `让模型在当前沙箱里改代码。改完去右侧运行校验。` |
| 任务与提示词 | `题目背景与分级提示词。不知道从哪下手就用第 1 级。` |
| 沙箱 | `模型的工作目录。可以清空改动重来，或打开目录自己看。` |
| 校验 | `跑一遍隐藏测试，给这一轮打分。约 1-5 分钟，可反复跑。` |
| 本轮备注 | `给这一轮记句话，只存在本机。` |

### 2.2 消除重复

- **卡头摘要与卡内状态只能有一处**。规则：卡头摘要只显示**动态变化的事实**
  （改了 n 个文件 / 得分 85 / 正在跑），空态时留空。
- 「模型档案已删除」这类**异常**只出现一次，放在动作按钮旁（那是用户要处理它的地方）。

### 2.3 主次分明

- **对话卡是主体**（用户 80% 时间在这里），给它最大的空间与最强的视觉权重。
- 右侧三张卡是**辅助**：紧凑、可折叠、默认收起（校验卡除外——它是结果出口）。

### 2.4 排版纪律（解决"黏在一起"）

- 对话消息之间：`gap: var(--space-4)`（16px），消息内 padding ≥12px
- 工具轮摘要与正文之间必须有可见分隔
- 正文行高 ≥1.7（CJK）
- 任何两个可点元素之间的间距 ≥8px

## 三、具体改造

### 3.1 内置对话卡

```
┌─ 内置对话 ──────────────────────────────── [模型档案 ▾] [状态] ─┐
│ 让模型在当前沙箱里改代码。改完去右侧运行校验。                  │
├────────────────────────────────────────────────────────────────┤
│  (消息流，内部滚动，gap 16px)                                   │
│                                                                │
├────────────────────────────────────────────────────────────────┤
│  [输入框]                                                      │
│  [发送当前提示词](ghost)                    [发送](primary)     │
└────────────────────────────────────────────────────────────────┘
```

要点：
- **模型档案下拉移到卡头右侧**（它是"这一轮用哪个模型"的设置，不是对话内容）
- 状态点（就绪/对话中/已交卷）紧邻下拉，不重复在别处
- 说明行在标题下方，字号小一档、颜色弱一档
- 输入区与消息流之间有 hairline 分隔

### 3.2 校验卡（用户点名"不知道做什么"）

```
┌─ 校验 ───────────────────────────────────── [上次 85 分] ─┐
│ 跑一遍隐藏测试，给这一轮打分。约 1-5 分钟，可反复跑。      │
├──────────────────────────────────────────────────────────┤
│  [运行校验 G](primary)  [查看参考解](ghost)  [导出报告]   │
│                                                          │
│  （跑完后）────────────────────────────────────────────  │
│  ✓ 通过 12/16 组 · 得分 85                               │
│  失败 4 组（点击展开看失败用例）                          │
│  [进入下一轮](primary)                                    │
└──────────────────────────────────────────────────────────┘
```

要点：
- **说明行说清"这步做什么 + 耗时 + 可重复"**（用户原话：不知道校验是做什么的）
- 结果区**编号化**：通过几组/共几组、得分、失败明细
- 空态不再只写"还没有跑过校验"，补一句"在对话里让模型改完代码后点上面的按钮"

### 3.3 沙箱卡

```
┌─ 沙箱 ────────────────────────── [就绪 · 已改 3 个文件] ─┐
│ 模型的工作目录。可以清空改动重来，或打开目录自己看。      │
├──────────────────────────────────────────────────────────┤
│ [打开目录] [清空改动] [重建沙箱]                          │
│ ▸ 详情（路径 / 基线指纹 / 日志）                          │
└──────────────────────────────────────────────────────────┘
```

### 3.4 任务与提示词卡

```
┌─ 任务与提示词 ─────────────────── [第 1 级 · 953 字] ─┐
│ 题目背景与分级提示词。不知道从哪下手就用第 1 级。      │
├───────────────────────────────────────────────────────┤
│ 题目简介（3 行截断 + 展开）                            │
│ ─────────────────────────────────────────────────────  │
│ 第 1 级提示词（症状级）  [发送到对话] [展开查看]        │
└───────────────────────────────────────────────────────┘
```

### 3.5 待办清单（按优先级）

1. 给每张卡加说明行（改动小、收益最直接）
2. 消除重复状态（卡头/卡内只留一处）
3. 对话卡：模型下拉移到卡头、输入区加分隔、消息 gap 加大
4. 校验卡：说明行重写 + 结果区编号化
5. 排版纪律：行高、间距按 §2.4 统一

## 四、验收标准

- [ ] 五张卡每张都有一行"这一步做什么"的说明
- [ ] 同一事实不在两处重复显示
- [ ] 对话消息之间 gap ≥16px，工具轮与正文有可见分隔
- [ ] 校验卡说清了"做什么/多久/能否重复"，结果区有明确的通过组数
- [ ] 1440 / 1920 两档宽度下无元素重叠、无文字挤压
- [ ] 所有功能保留（轮询、快捷键、promote、揭晓、导出、备注）
