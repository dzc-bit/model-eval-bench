# 派发说明（这份不给 agent，你自己看）

三份提示词分别对应三个 agent。每份都是自包含的：直接整段复制发给一个能打开本仓库的 agent 即可。

## 建议的执行顺序

1. **01 题目校验** —— 以读和报告为主，基本不改代码，任何时候都能跑，可以和 02 并行。
2. **02 前端重构** —— 大改 `console/static/**`，改动面最大，单独跑。
3. **03 项目整理** —— 放在最后。它会动 `console/` 前后端，如果和 02 并行必然撞车；
   而且 02 重构完会产生新的死代码，03 最后收尾正好一起清掉。

即：**01 任意时刻，02 → 03 串行**。

## 派完后你要做的事

- 每个 agent 干完都会按提示词里的验证门禁自验，但「他说绿就是这几条全绿」的口径在
  `AGENTS.md` 里，你过一遍它的验证输出再放行。
- 01 的产出是报告，改不改题目由你拍板（`packs/` 默认只读，agent 被要求先报告再动手）。
- 02 改的是 UI，验证门禁里有一条是「浏览器里真的点一遍」，别只看它贴的测试绿。
