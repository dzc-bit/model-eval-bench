# 任务：模型身份归并——同一模型在记分板/排行榜只占一列

你是后端统计负责人。仓库 <仓库根目录>。先读 `AGENTS.md`（时间与统计口径、删除语义两节必守）、
`console/harness/runs.py` 的 scoreboard/leaderboard 聚合与 `_cell_stats`/`_counted_rounds`、
`console/harness/config.py` 的 `legacy_ids` 与读时迁移。

## 问题

模型配置从「平铺档案」重构成「供应商→模型」后，同一个真实模型有两种身份：

- 历史运行记录的 `run.model` = 老档案 id（如 `cbcn-deepseek-v4-1-flash`）
- 新跑的记录 = 新扁平 id（如 `cbcn/deepseek-v4.1-flash`）

结果：记分板与排行榜把同一模型显示成两列/两行，成绩被劈开。供应商条目里已有
`legacy_ids`（读时迁移记下的老档案 id），但统计没有用它。

## 修复思路（按这个做）

1. **读侧归并，不改记录**：`run.model` 字段是历史事实，永不改写；归并只发生在
   scoreboard / leaderboard 的聚合阶段。
2. 聚合前先把每条 run 的 `model` 归一到**当前档案身份**：
   - 命中某供应商的 `legacy_ids` 或其下模型的 id/qualified 形态 → 归到该模型的当前 id；
   - 命中不到任何现存档案（档案已删）→ 保持原名展示，走既有 `model_gone` 语义，不归并。
3. 显示：归并后该列用当前档案名（老名字不再单列）；CSV 导出与 scoreboard note 同步口径。
4. **统计口径不变**：作数尝试、voided/invalidated 排除、均分=每 run 最佳作数轮的均值——
   这些刚修好的语义一个都不能变，只是分组的 key 换了。
5. 排行榜（leaderboard）与记分板必须同口径（红线），两边都改。

## 验证

- 新增测试锁定：同一供应商下「老 id 记录 + 新 id 记录」聚合成一列，trials/pass@1/均分
  数字正确；已删档案的记录不归并、仍单列。
- 本机有现成数据可直接看效果：T1-01 等题的记录挂在 `cbcn-deepseek-v4-1-flash`，
  修完后记分板应只剩一列且数字不变（修前 2 次通过/4 次尝试，修后应一样，只是列名换了）。
- 门禁：`EVAL_PYTEST_TMP=<全新临时目录> python -m pytest console/harness/tests -q` 全绿；
  `python console/harness/selfcheck.py` 0 错误 0 提示；前端若动 .js 则复制成 .mjs 后
  `node --check` 全过；最后开浏览器（http://127.0.0.1:8899，服务在跑）看记分板/排行榜实际效果。
- 不执行任何 git 提交/回退，提交由主 agent 统一做。
