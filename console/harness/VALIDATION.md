## 聊天与推理展示

- 保存并展示接口实际返回的文本 reasoning_content / reasoning，工具续轮与历史回放保留原字段名。
- 思考区域默认展开，可折叠；刷新恢复历史。接口没有返回文本推理时给出明确提示。
- 请求处理期间读取已保存的模型/工具回合，最终回答之前即可显示前一回合的推理；当前不是逐 token 流式传输。
- Mock 验收覆盖发送、工具消息、推理展开/折叠、缺失字段提示、刷新恢复和提交评分。
- 另启独立目录的真实 harness 服务与本地 HTTP 协议桩，验证浏览器 → HTTP 代理 → write_file → 工具结果 → 下一模型回合。
  实际写入仅发生在测试沙箱，文件内容已核对；返回历史不含测试认证值。协议桩还验证了续轮中的推理字段未丢失。
- 本地协议桩不是外部模型。没有对模型隐藏思维链作出可获取承诺，也不从最终答案生成伪造推理。

## 排行榜与取消

- 单题排行榜用明确标记的 mock 通过记录验收排名布局；390px 视口没有页面横向溢出。
  该记录只在测试浏览器 sessionStorage 中，不写入正式成绩。
- 批量接口的 mock 尚未实现，因此取消验收使用真实后端和独立 fixture 目录。
- 实测 2 题 × 2 档案、并发 1：取消时一条已准备、三条仍排队；最终四条均 cancelled，
  仅第一条产生 run_id，该沙箱回收，排队条目没有继续派发，前端取消按钮进入禁用状态。
- 取消语义为协作取消：停止新派发、准备阶段退出，已开始评分的进程允许收尾。
  清理或评分收尾期间保持 cancelling。评分期间取消由后端现有窄测试覆盖。
- auto_release=False 的调用方选择保留目录时，取消也遵循该保留选项。

## 外部条件与范围限制

- 当前正式档案 ID=1、model=1，base_url 为空，使用默认接口地址；未发现可用服务端密钥。
  需配置实际 endpoint、模型名和服务端密钥并重启服务，才可进行真实服务商验收。
- 真实外部模型调用、上游推理字段是否开放、真实难度校准均未验证。
- 文件夹与命令参数约束不等于操作系统级安全隔离。运行于沙箱的程序仍具有服务进程的本机权限；
  若要执行不可信代码，需要独立账户、容器或虚拟机等另行设计的隔离边界。
